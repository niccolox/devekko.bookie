bookie
Agent Skills for Claude Code and other agents

Set the kill criteria before your agent writes line one.

Your agent can build the app in an afternoon. Bookie runs each idea as a bet: fixed terms, a thin build, real users, and a go, no-go, or pivot call on a date you pick first.

The terms of every bet

📝

Terms first

A core question, 3 to 6 kill criteria with numbers, and a decision date. All before any code.

🔒

Terms stay put

After the frame stage, no agent changes a criterion or the date. Only you can.

👀

Only acts count

A second login or a payment goes in the log. A compliment goes nowhere.

⚖️

Settled on the date

The agent runs the evidence again. Each criterion is met or not met. You make the call.
